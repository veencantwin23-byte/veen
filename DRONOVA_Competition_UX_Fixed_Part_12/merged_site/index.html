ABOUT DRONOVA

Dronova — Interactive 3D Drone Learning Application

Purpose

Dronova is a Final Year Project built to teach the fundamentals of drone technology through hands-on, visual, interactive learning rather than static text alone.

Educational Objective

Help learners understand what a drone is, how its components work together, and how basic flight is controlled — connecting theory (Learn), inspection (3D Lab), practice (Simulator), and assessment (Quiz) into one flow.

Target Users

Students and hobbyists with no prior drone knowledge, educators looking for an interactive teaching aid, and anyone curious how multirotor drones actually work.

Main Features

A 6-module Learning System, an interactive exploded-view 3D Drone Lab (77 real components), a physics-based Flight Simulator with guided training and missions, a randomized Quiz system, and a Progress & Achievement dashboard.

Technologies Used

Three.js (WebGL 3D rendering), vanilla JavaScript with no framework dependency, and browser localStorage for client-side progress persistence — no backend or account system required.

Educational Context

Developed as a Final Year Project demonstrating applied web-based 3D visualization and interactive educational design for technical subject matter.
