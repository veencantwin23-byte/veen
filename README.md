# DRONOVA

Interactive drone learning platform.

## Project structure

- `index.html` — app shell and page navigation
- `dronova_scene.js` — page setup, viewer bridge, page routing, auth modal
- `dronova_learn.js` — learning modules, dashboard, search, component explorer
- `dronova_quiz.js` — quiz system
- `dronova_progress_core.js` — centralized progress, XP, achievements
- `dronova_progress_ui.js` — progress dashboard renderer
- `dronova_resources.js` — glossary and references
- `data/` — learning data, glossary, quiz bank, component metadata
- `drone-viewer/` — 3D exploded drone viewer
- `simulator/` — flight simulator page

## Notes

This repo is scaffolded for the DRONOVA app architecture described in the project files. Replace the placeholder content with the final implementation as needed.
